# Security policy

Please report suspected vulnerabilities privately through GitHub’s repository security
advisory process or directly to the repository owner. Do not include real credentials,
cloud evidence, raw audit artifacts, personal data, or screenshots in public reports.

`ccm-audit-export` performs no network access or credential handling. Consumers remain
responsible for source-evidence classification, redaction approval, package storage,
transfer, retention, deletion, access control, independent review, and any audit or
authorization decision.
